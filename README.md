Project Goal: Create a fully functioning bracket-creating algorithm. Players' stats and previous game information are used to balance brackets.

MVP Scope: 
Takes players and their stats through the terminal
Arranges a bracket based on stats
Prints the finished bracket inside the terminal

Future Goals: 
Integrate doubles and singles player functionality
Information about players can be taken in through a CSV file instead of the terminal
Add the brackets to a file and let the user download the file

Tech Stack: 
Java - familiar with it from using it in class
JSON file - to store internal records
Libraries and tools: Java’s built-in Arrays, ArrayLists, and the java.io library
Data Sources: N/A; users manually input information; nothing is gathered from outside
